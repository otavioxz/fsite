Coloque aqui seus arquivos de áudio (mp3) para o player do site.

Os nomes devem bater com o que está configurado em js/config.js,
dentro de CONFIG.songs -> "src". Por padrão o config espera:

  assets/audio/track1.mp3
  assets/audio/track2.mp3

Pode adicionar quantas faixas quiser, só seguir o mesmo padrão
(adicionar um novo objeto { title, artist, cover, src } no array
CONFIG.songs em js/config.js).

Importante: use apenas áudios que você tem direito de usar
(músicas próprias, livres de direitos autorais, ou licenciadas),
já que o site ficará hospedado publicamente.
